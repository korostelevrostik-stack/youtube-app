1. Какие данные мы собираем

Наше приложение использует YouTube Data API v3 и Google OAuth 2.0 для авторизации. Мы можем запрашивать доступ к:

  • Базовой информации профиля Google (имя, email, ID пользователя) — для входа в приложение и идентификации.
  • Действиям с YouTube (лайки, подписки) — для сохранения ваших предпочтений в нашем приложении.

Мы НЕ собираем, не храним и не передаём третьим лицам ваши пароли, историю просмотров или другие личные данные, не связанные с работой приложения.

2. Как мы используем ваши данные

  • Для аутентификации вас как пользователя.
  • Для сохранения ваших лайков и подписок в нашем приложении.
  • Для улучшения пользовательского опыта.

3. Хранение и удаление данных

Ваши данные (Google ID, имя, email) хранятся в нашей базе данных только до тех пор, пока вы используете приложение. Если вы захотите удалить свои данные, вы можете:

  • Написать нам на ooaoooa4562@gmail.com.
  • Или войти в приложение и нажать кнопку "Удалить мои данные" (если она есть).

Мы удалим ваши данные в течение 7 рабочих дней с момента вашего запроса, как того требуют правила YouTube API [citation:1].

4. Передача данных третьим лицам

Мы НЕ передаём ваши данные третьим лицам. Данные используются исключительно внутри нашего приложения и хранятся локально.
